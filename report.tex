\section{Overview}
This project extends the MiniML language with support for exceptions. Specifically, we added two new exception mechanisms:
\begin{itemize}
    \item \texttt{DivisionByZero}
    \item \texttt{GenericException}
\end{itemize}
We modified the abstract machine implementation in \texttt{machine.ml} to support raising and catching exceptions using the \texttt{IRaise} and \texttt{ITry} instructions.

\section{Machine Architecture}
The abstract machine executes MiniML programs using:
\begin{itemize}
    \item A \textbf{stack of frames} representing program code.
    \item A \textbf{stack of values} for evaluation.
    \item A \textbf{stack of environments} for variable bindings.
\end{itemize}

A machine value (\texttt{mvalue}) can be:
\begin{itemize}
    \item An integer (\texttt{MInt})
    \item A boolean (\texttt{MBool})
    \item A function closure (\texttt{MClosure})
\end{itemize}

\end{lstlisting}

\begin{lstlisting}
IRaise of string
ITry of frame * (name * frame) list
\end{lstlisting}

\section{Exception Handling Semantics}
\subsection{IRaise}
This instruction immediately raises a named exception. For example:
\begin{lstlisting}
| IRaise exn_name -> raise (Machine_error exn_name)
\end{lstlisting}

\subsection{ITry}
This instruction implements \texttt{try ... with ...} by:
\begin{enumerate}
    \item Executing the \texttt{try} block.
    \item Catching exceptions and matching them to handlers.
    \item Executing the matched handler block if found.
\end{enumerate}

\section{Division By Zero}
Division is now guarded against divide-by-zero errors using:
\begin{lstlisting}
| IDiv -> 
    try (frms, div stck, envs)
    with Failure _ -> raise (Machine_error "DivisionByZero")
\end{lstlisting}

\section{Sample Example}
An example demonstrating exception handling:
\begin{lstlisting}
try
  let x = 10 / 0 in x
with
  DivisionByZero -> 0
\end{lstlisting}

This will produce the result \texttt{0} due to catching the divide-by-zero.

\section{Limitations}
\begin{itemize}
    \item Only string-tagged exceptions are supported.
    \item Stack unwinding is minimal; no backtrace or nested \texttt{try} evaluation.
\end{itemize}
